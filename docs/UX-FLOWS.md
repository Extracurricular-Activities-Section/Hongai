# UX Flows

弘愛築夢申請管理系統 — 重構後的介面流程與資訊架構。

> 本文件描述「使用者看到什麼、怎麼走」。狀態機與權限規則見 `APPLICATION-WORKFLOW.md`、`SECURITY-ARCHITECTURE.md`；本次重構未更動任何一條。

---

## 1. 資訊架構

### 學生端（水平主導覽，5 項）

```
首頁 · 本期申請 · 追蹤任務 · 通知 · 我的資料
                                    └─ 歷史申請（併入我的資料）
```

### 後台（左側深色 rail，三組）

```
工作區
  ├─ 儀表板
  ├─ 追蹤任務
  └─ 通知中心
案件
  ├─ 申請案件
  ├─ 學生資料
  └─ 正式文件
設定
  ├─ 申請梯次
  ├─ 表單主檔 → Form Builder
  ├─ 單位管理
  ├─ 通知範本 / 追蹤任務範本
  ├─ 身分重設申請
  └─ 帳號管理（Admin only）
```

導覽項目仍依 `useBackofficeAuth()` 的角色決定顯示與否，規則未變。

## 2. 學生流程

### 2.1 登入與註冊

`PublicLayout` 左側為深色品牌欄（系統名稱、說明），右側 `AuthCard`。所有欄位透過 `Field`，錯誤訊息掛在欄位下方並以 `aria-describedby` 關聯。註冊、驗證、登入協助共用同一版型。

### 2.2 首頁（`/student`）

由上而下四段，回答「我現在該做什麼」：

1. **問候列** — 姓名、學號、系所、年級。
2. **本期梯次 Hero** — 梯次名稱、開放期間、剩餘天數；主 CTA「前往本期申請」為畫面唯一萊姆按鈕。無開放梯次時改顯示說明文字。
3. **指標列（`MetricRow`）** — 進行中 / 已送出 / 需補件 / 待辦任務，每個數字都是連結。
4. **需要你處理（`AttentionRow`）** — 補件、退回、逾期任務彙整成單一清單，每列直接連到可處理的頁面。

### 2.3 本期申請（`/student/current`）

九個申請類別以卡片呈現。每張卡片：類別名稱（連結）、狀態 Badge、關鍵資訊（金額／期限／缺件提示）、主要行動按鈕。未開放的類別維持停用外觀並說明原因。

### 2.4 填表工作區（`/student/current/:categoryCode`）

專注模式版型，抽掉一般頁面的裝飾：

```
┌─────────────────────────────────────────────────┐
│ 頂部列：梯次 · 類別 · 申請人 · 自動儲存狀態      │
├──────────┬──────────────────────────────────────┤
│ 區段導覽 │  表單內容（固定約 680px 寬）          │
│ StepRail │  Field × N                            │
│ (完成／  │                                       │
│  目前／  │                                       │
│  未填)   │                                       │
├──────────┴──────────────────────────────────────┤
│ StickyActionBar：SaveIndicator + 上一段/下一段/完成 │
└─────────────────────────────────────────────────┘
```

- 自動儲存狀態以 `SaveIndicator` 顯示（儲存中 / 已儲存 / 失敗），`aria-live="polite"`。
- 驗證時機、規則引擎、computed fields 皆沿用 `FORM-ENGINE.md`，未更動。
- 錯誤集中在欄位層級呈現，送出前的阻擋條件顯示於固定操作列上方。

### 2.5 正式文件與送件

`StudentPdfPanel` 以 `ProcessStepper` 攤平紙本流程：

```
完成填寫 → 產生申請表 → 列印並簽名 → 送交承辦
```

- 尚未產生 PDF：虛線框空狀態 + 「產生 PDF」。
- 已產生：有效版本卡（文件編號、版本、產生時間）+ 下載／預覽／重新編輯／重新產生。
- 內容修改後：`InlineNotice tone="attention"` 提醒需重新產生。
- 舊版本收在可展開的「文件版本紀錄」，不佔主視線。
- 需上傳簽名文件時，`StudentSubmitPanel` 接在其後；未上傳則明確擋住送出並說明原因。

### 2.6 附件上傳

`SecureFileUpload` 改為虛線投放區：上傳圖示、選擇檔案按鈕、格式／大小／數量限制說明。已上傳檔案為單列清單（檔名、大小、預覽／下載／刪除 icon 按鈕，皆有 `aria-label`）。預覽在原地展開，可關閉。

### 2.7 追蹤任務、通知、歷史

- **追蹤任務** — `TaskCard` 清單，逾期以 `critical` tone 標示。
- **通知** — 活動流形式，未讀以萊姆點標記；上方 `FilterBar` 提供類型與已讀狀態篩選。
- **歷史申請** — 依梯次分組，唯讀。歷史表單頁沿用同一 renderer 的 `mode="view"`。

## 3. 後台流程

### 3.1 儀表板（`/admin`）

行動導向而非統計導向：

1. **待處理指標列** — 待審核、需補件、逾期任務等，每個數字連到已套好篩選的列表。
2. **狀態分佈** — 目前梯次的案件狀態橫向分佈。
3. **需要注意** — 逾期與異常項目直接列出。

### 3.2 申請案件列表（`/admin/applications`）

CRM 式列表：`FilterBar`（梯次／類別／狀態／單位 + 搜尋）在上，`DataTable` 高密度表格在下。整列可點（`LinkRow`），分頁在底部。空狀態與錯誤狀態使用共用元件。

### 3.3 案件詳情（`/admin/applications/:id`）

70 / 30 分欄：

```
┌───────────────────────────────┬──────────────────┐
│ PageHeader（學生 · 類別 · 狀態）│ ContextPanel      │
│ Tabs                          │  ├ 申請人摘要      │
│  ├ 表單內容                    │  ├ 金額／資格摘要  │
│  ├ 附件                       │  ├ 歷程 Timeline  │
│  └ 追蹤任務                    │  └ 情境動作       │
└───────────────────────────────┴──────────────────┘
```

- 右欄動作依目前狀態顯示，對應的 API 呼叫與確認流程完全沿用原有邏輯。
- 破壞性動作（退回、駁回）使用 `danger` 變體並經 `ConfirmDialog`（Radix，具 focus trap）。

### 3.4 Form Builder（`/admin/forms/:id/builder`）

工具型三欄版面，滿版高度：

```
┌──────────────────────────────────────────────────────────┐
│ Topbar：返回 · 表單名稱/版本 · 儲存狀態 Badge · 復原/重做 · 預覽 · 發布 │
├──────────┬───────────────────────────┬───────────────────┤
│ Palette  │ Canvas                    │ Inspector          │
│ 欄位型別  │ 區段／欄位（拖曳排序）      │ 選取項目的設定      │
│ 15rem    │ 1fr                       │ 21rem              │
└──────────┴───────────────────────────┴───────────────────┘
```

- Canvas 上的操作改為 icon 按鈕（拖曳握把、上移、下移、複製、刪除），hover / focus 時顯現，全部有 `aria-label`。
- 選取項目以 `accent` 邊框與 `accent-soft` 底標示。
- 拖曳行為（`@dnd-kit`）、自動儲存、版本與發布邏輯未更動。
- 預覽改用 Radix `Dialog`，具 focus trap 與 Esc 關閉；可切換桌機／手機寬度。
- 視窗寬度不足時顯示 `EmptyState` 建議改用桌機，並仍提供預覽入口。

## 4. 共通狀態規範

| 狀態 | 呈現 |
| --- | --- |
| 首次載入 | `PageSkeleton`（頁）／`SkeletonList`、`SkeletonTable`（區塊） |
| Auth 還原中 | `PageLoader` 全頁等待 |
| 無資料 | `EmptyState`：圖示 + 標題 + 一句說明 + 主要動作 |
| 錯誤 | `ErrorState`：可重試時附重試按鈕 |
| 提示 | `InlineNotice`：不打斷流程的說明或警告 |
| 表單送出中 | 按鈕 `disabled` + 文案切換，避免重複送出 |
| 例外崩潰 | `AppErrorBoundary` 全頁畫面，提供重新載入／返回首頁 |

## 5. 響應式斷點

| 範圍 | 行為 |
| --- | --- |
| `< 640px` | 單欄；導覽收進 `Sheet`；表格改卡片式；固定操作列貼底。 |
| `640–1024px` | 兩欄指標；後台表格水平捲動並固定首欄語意。 |
| `≥ 1024px` | 後台 sidebar 常駐；詳情頁 70/30；Form Builder 三欄。 |
| `≥ 1280px` | 內容最大寬度收斂，避免長行影響閱讀。 |

Form Builder 在 `< 1024px` 不提供編輯介面，僅提供預覽。
